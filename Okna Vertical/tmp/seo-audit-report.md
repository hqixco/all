# Проверка сайта «Окна Вертикаль»

Проверена production-сборка: 26 индексируемых страниц и страница 404. Отдельно проверены HTTP-ответы опубликованного сайта.

## Исправлено

- Удалена скрытая старая страница из HTML главной: второй H1 и повторяющиеся ID. Используемые модальные окна сохранены.
- Добавлен H1 страницы 404; сохранён запрет её индексации.
- Исправлено мобильное переполнение блоков перехода между услугами на страницах балконов.
- Изображения получают фактические width и height при генерации HTML, включая ранее пустые атрибуты.
- Сокращён title страницы балконов без изменения её видимого заголовка.
- Добавлено перенаправление www на основной домен в public/.htaccess.
- Обновлена уязвимая транзитивная зависимость nanoid. npm audit: 0 уязвимостей.
- Добавлена воспроизводимая проверка scripts/check-site-seo.mjs; актуализированы проверки интерактивных компонентов с учётом разных моделей калькулятора и скрытых вкладок.

## Результаты проверок сборки

- Уникальные title и description, один H1, правильный lang и canonical: 27 страниц.
- Sitemap содержит все 26 индексируемых страниц; canonical и sitemap согласованы.
- Все страницы доступны по внутренним ссылкам с главной; страниц без входящих переходов не найдено.
- Нет битых внутренних ссылок, отсутствующих якорей, повторяющихся ID и ошибок JSON-LD.
- Нет предупреждений об отсутствии alt или размеров у изображений с заданным src.
- 25 подстраниц проверены на ширинах 1920, 1536, 1440, 1301, 1200, 1024, 768, 600, 390 и 320 px: переполнения, битые картинки и обрезанные цены не найдены.
- Главная проверена на восьми ширинах 1920–320 px и без JavaScript. Видимые фотографии тяжелее 300 КБ не найдены.
- Проверены квизы, калькуляторы, галереи, попапы и локальное поведение форм. Постоянный контент всех подстраниц доступен без JavaScript.
- Проверка шапки: 27 маршрутов, семь ширин; меню и закрытие по Escape работают.
- Общие компоненты, структура страниц, отсутствие br и классический синтаксис media queries в собранном CSS проходят проверки.
- Оптимизированные изображения SEO-страниц: 38 файлов, максимальный вес 162 346 байт.

## Что остаётся на опубликованном сайте

На сервере находится старая версия, отличающаяся от проверенной сборки:

- robots.txt указывает https://okna-vertikal.ru/sitemap.xml — неверный домен.
- Содержимое опубликованного sitemap также использует okna-vertikal.ru.
- Главная содержит второй H1 из старой скрытой страницы.
- Проверенный URL /okna-v-kvartiru без завершающего слеша возвращает 404; актуальная сборка возвращает 301 на URL со слешем.
- https://www.okna-vertical.ru/ возвращает 200 вместо перенаправления на основной домен.

Исправления подготовлены в проекте. Публикация в рамках этой проверки не выполнялась. После загрузки dist нужно проверить правила Apache/.htaccess на реальном хостинге.

## Границы проверки

Реальные заявки в CRM, Telegram и почту не отправлялись. Локальный режим форм имитирует успешную отправку; он не подтверждает доставку обращений сервером. На живом сайте обработчик mail.php отвечает 405 на GET, что ожидаемо для обработчика POST.

Данные Яндекс Вебмастера, Google Search Console и полевые Core Web Vitals недоступны в этой проверке. Индексацию, позиции и показатели реальных посетителей нельзя подтвердить локальной сборкой. Старый Safari не запускался: проверены target сборщика и синтаксис итоговых медиазапросов; браузерные проверки выполнялись в Chromium.

Ориентир технической проверки: [Google Search Central — руководство для разработчиков](https://developers.google.com/search/docs/fundamentals/get-started-developers), [требования к sitemap](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap).
