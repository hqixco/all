# Окна Вертикаль

Базовое окружение проекта на Vite, HTML, CSS и vanilla JavaScript.

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
npm run preview
```

SEO-страницы создаются перед запуском и сборкой: данные находятся в `seo-pages/data.js`, общий шаблон и блоки — в `scripts/generate-seo.mjs`. Контент записывается в HTML и доступен без JavaScript. Сгенерированные `*/index.html` не редактируйте вручную: следующая сборка обновит их из данных и шаблона. Типовые блоки главной и страницы квартиры собираются из общих шаблонов `components/*.html` и данных `seo-pages/components/*.js`. Инструкция по новым страницам — [components/readme.md](components/readme.md). Управляемые области главной отмечены комментариями `component:...`; правьте шаблоны и данные. Остальная разметка главной и `balkony/index.html` остаётся самостоятельными исходниками.

Публикуйте содержимое `dist`, включая скрытый `.htaccess`. На Apache он включает настоящий HTTP 404 и нормализацию URL каталогов. Для Nginx используйте `try_files $uri $uri/ =404;` и `error_page 404 /404.html;`, без перенаправления неизвестных адресов на главную. На другом хостинге назначьте `404.html` страницей ошибки со статусом 404.

Формы используют существующий `/mail.php`, `page_url` и цели Метрики. Поле `source_name` описывает услугу. Локальный режим отправки в `src/main.js` имитирует успех: проверку реальной почты/CRM выполняют на PHP-хостинге.

Отчёт об изменениях и данные для уточнения: `seo-report.md`.
