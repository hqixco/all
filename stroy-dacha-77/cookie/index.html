1. Что такое cookie

Cookie - это небольшие фрагменты данных, которые сайт сохраняет в браузере посетителя. Они помогают корректно отображать страницы, сохранять настройки, анализировать посещаемость и улучшать работу сайта.

  • для корректной работы сайта и форм обратной связи;

  • для предотвращения повторного показа уведомлений;
  • для анализа посещаемости и действий пользователей;
  • для выявления технических ошибок;
  • для оценки эффективности рекламных кампаний;
  • для защиты сайта от технических нарушений.

3. Категории cookie

Необходимые cookie

Нужны для базовой работы сайта, отображения страниц, работы форм и сохранения технических настроек. Отключение таких cookie может нарушить работу отдельных функций.

Аналитические cookie

Помогают понять, какие страницы посещают пользователи, откуда они приходят, сколько времени проводят на сайте и с какими элементами взаимодействуют.

Функциональные cookie

Могут использоваться для сохранения состояния форм, выбранного способа связи и других пользовательских настроек.

Рекламные cookie

При подключении рекламных систем могут использоваться для определения источника перехода, оценки эффективности объявлений и формирования статистики обращений.
