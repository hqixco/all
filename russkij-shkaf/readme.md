# Русский Шкаф

География: Санкт-Петербург и Ленинградская область.

Проект на Vite, HTML, CSS и vanilla JavaScript. Первый экран собран по предоставленному макету. Вторым блоком расположен квиз по аналогии с Okna Vertical: четыре вопроса, прогресс, выбор вариантов и возврат к предыдущим ответам.

На финальном шаге квиза доступны телефон, имя, комментарий и кнопка «Рассчитать шкаф». Для подключения отправки задайте `VITE_QUIZ_ENDPOINT` в `.env.local` и пересоберите сайт. Обработчик должен принимать POST FormData с полями `wardrobe`, `size`, `facade`, `timing`, `phone`, `client`, `comment`, `package` (выбранная комплектация, если переход был из карточки) и возвращать успешный HTTP-статус только после принятия заявки. При другом домене обработчик должен разрешать CORS для сайта. Без адреса обработчика форма сообщает, что отправка не подключена. Слева в квизе — видеообращение Светланы с запуском по нажатию и звуком; без JavaScript доступны стандартные элементы управления.

Форма сравнения смет отправляет POST FormData с полями `estimate` (файл), `phone`, `consent` и `request_type`. Можно задать отдельный `VITE_COMPARE_ENDPOINT`; если он не задан, используется `VITE_QUIZ_ENDPOINT`. Обработчик должен принимать файл и возвращать успешный HTTP-статус только после получения заявки.

## Запуск

```bash
npm install
npm run dev
```

## Production-сборка

```bash
npm run build
npm run preview
```

Сборка находится в `dist`. Имена файлов сохраняются без хешей. JavaScript и CSS настроены на Safari 13.

## Структура

- `index.html` — весь постоянный контент, карточки, формы и модальные окна.
- `src/styles.css` — все стили сайта, подключения Inter и адаптация блоков.
- `src/main.js` — квиз, переключение фото кейса, галерея производства, меню и модальное окно контактов.
- `public/assets/` — оптимизированные изображения и локальные шрифты Inter.
- `vite.config.js` — сборка для Safari 13 со стабильными именами `assets/styles.css` и `assets/main.js`.

На странице: первый экран, квиз, три кейса, популярные решения, наполнение, установка, материалы, стоимость, производство, шоурум и тёмный подвал. Контейнеры 1140 px.

Имена файлов: латиница в нижнем регистре, цифры и дефисы. Постоянный контент находится в HTML, без JavaScript-рендера. Для адаптации используются только `max-width`, без `!important`.
