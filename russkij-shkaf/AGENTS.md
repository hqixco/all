# CSS-правила проекта

- Все адаптивные `@media`-запросы размещать в конце CSS-файла после основных стилей.
- Располагать запросы по ширине экрана в убывающем порядке: от большего `max-width` к меньшему.
- Для каждой ширины использовать один общий медиаблок. Если он уже есть, дополнять его, а не создавать новый.
- Запросы по предпочтениям пользователя, например `prefers-reduced-motion`, размещать после медиаблоков ширины.
# Разметка текста

- Не использовать HTML-элемент принудительного переноса текста.
- Переносы оставлять естественными; `&nbsp;` использовать только между словами, которые нельзя разрывать переносом строки.
