# Stroybrigada Theme

## Заявки в MAX

Chat ID чата «Заявки Стройбригада 365» — `-79313277509822`. Он указан в настройках темы по умолчанию. В WordPress откройте «Настройки заявок» и сохраните токен бота; после этого отправка включится. Токен можно хранить в `wp-config.php` через константу `STROYBRIGADA_MAX_BOT_TOKEN`, а ID — через `STROYBRIGADA_MAX_CHAT_ID`. Не добавляйте токен в файлы темы.

ID получен из события `bot_added` и сверен с названием чата через API MAX. Запросы к MAX используют сертификат Минцифры из `inc/certs/russian-trusted-root-ca.crt`; при его обновлении замените файл сертификатом из официального источника. После отправки заявки результат виден в журнале заявок как `max: sent`, `failed` или `skipped`.

Кастомная тема WordPress для переноса сайта `stroybrigada-365.ru` из текущей Vite-версии.

Основные каталоги:

- `inc/` — инфраструктура темы;
- `template-parts/` — секции и глобальные части;
- `assets/dist/` — production-ассеты;
- `acf-json/` — ACF Local JSON;
- `data/` — источники для импорта.

Импорт начальных данных запускается вручную:

- `Внешний вид -> Импорт Stroybrigada`

Импортёр идемпотентен: записи помечаются мета-ключом `_stroybrigada_source_id`, повторный запуск обновляет существующие объекты вместо создания дублей.
