# Источники цен

Актуальный единый реестр: config/site-prices.json. Строки общего прайса: config/prices-catalog.json. Метод и источники описаны в docs/site-prices.md.

Общий прайс и страницы услуг получают цены из одних записей; сторонние ориентиры явно отмечены. Предыдущая версия на 13 строк заменена общим прайсом на 47 строк.
