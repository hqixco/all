# Общие таблицы

Все 18 таблиц на 8 страницах используют shared-table.css по образцу таблицы главной и световых вывесок. Старые правила в CSS семейств удалены, включая горизонтальный скролл и превращение таблицы в карточки на мобильных. Содержимое ячеек и семантика table/th/td сохранены.

scripts/sync-table-styles.mjs добавляет статические классы и colgroup при сборке. Три колонки сохраняют соотношение 30/30/40; сравнительные таблицы с четырьмя и пятью колонками сжимаются пропорционально. Прайс сохраняет прежние пропорции 24/29/32/15.

Реестр данных для проверки: config/shared-tables.json. Проверка источников и production: scripts/table-styles-audit.mjs, включена в сборку.

Дополнительно переведены в table три сравнения, ранее свёрстанные через div/article с повторяющимися подписями колонок: вывески для магазина, навигация и оформление сети магазинов. Всего общий компонент используется в 21 таблице на 11 страницах. Все тексты данных и ссылки сохранены; повторяющиеся подписи вынесены в thead.
