# Фотографии в карточках кейсов

Устранён конфликт в 12 семейных стилях: правила вида `.facade-signs img` задавали `height:auto` также изображениям общего блока кейсов. Теперь эти правила назначены только собственным фотографиям семейных страниц через отдельные классы. Стили и кадрирование кейсов остаются общими с главной. Новые изображения и дополнительные переопределения CSS не добавлялись.

Проверены все 44 страницы с общим блоком кейсов на 1440 и 390 px; семь типов страниц дополнительно на 1000, 760 и 320 px. Всего 109 проверок, 1962 измерения изображений: размеры совпадают с рамками, используется `object-fit:cover`, горизонтального переполнения нет. Визуально проверены главная, фасадные и неоновые вывески на двух ширинах, включая переключение фото внутри карточки.

Проверки: `node tmp/case-images-check.mjs`, `node tmp/case-images-visual.mjs`. Отчёт: `tmp/case-images-report.json`. Production-сборка проходит.
