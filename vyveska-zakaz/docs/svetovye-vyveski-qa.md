# Финальный QA /svetovye-vyveski/

Статус: визуальная и локальная функциональная проверка выполнена; проверка реальной доставки заявки ожидает работающий PHP-хостинг. Страница остаётся `indexable: false`, `noindex, follow` и исключена из sitemap. Изменения других страниц не выполнялись.

## Визуальная проверка

Проверена production-сборка в headless Google Chrome, а не только исходный HTML. Снимки desktop 1440×1000, mobile 390×844 и 320×780 сохранены в `tmp/light-signs-qa-*.png`; журнал — `tmp/light-signs-browser-qa.json`.

- Первый экран: читаемый H1, реальные фото, работоспособные CTA. Кнопки подняты перед дополнительным абзацем; на узком mobile скорректирован размер заголовка.
- Карточки типов: две колонки на desktop, одна на mobile; фото сохраняют пропорции через object-fit: contain.
- Таблица: три столбца на desktop; на mobile прокручивается только её контейнер. Вся страница не имеет горизонтального скролла.
- Фото: все девять загружены и декодированы в браузере; width/height соответствуют файлам. Повтор project-658 в карточке комбинаций заменён другим реальным кадром project-664. Новый ассет сохраняет имя light-signs-combined.webp.
- FAQ: раскрытие и закрытие native details работают на всех трёх ширинах.
- Форма: поля заполняются, без согласия checkValidity возвращает false, после согласия — true. Исправлен чекбокс, который схлопывался до 0×0 из-за общего appearance: none.
- Меню: исправлены контраст desktop и положение mobile-панели, которая ранее уходила выше viewport. Открытие/закрытие и раскрытие группы проверены кликом.
- Хлебные крошки: ссылки доступны, переносы на mobile естественные; последовательность соответствует реестру.
- Подвал: ссылки ранее скрытых подменю собраны в раскрываемый блок «Все направления компании», остаются в статическом HTML и доступны кликом. Только на этой странице.
- Пустой плавающий элемент возврата наверх заменён обычной якорной ссылкой с SVG и доступным названием.
- Без JavaScript на mobile видны меню, контент и форма; FAQ работает нативно.

Ширина document.scrollWidth равна viewport: 1440, 390 и 320 px. Ошибок JavaScript нет. Локальная прокрутка таблицы на 390 px: clientWidth 350, scrollWidth 620.

## Реальная заявка: незавершённая проверка

У формы этой страницы тот же action `/mail.php`, поля и общий JS-обработчик, что у остальных локальных страниц. PHP-обработчик использует mail() и получателя `resurs_mi@mail.ru`.

Локальный Vite Preview не выполняет PHP. На основном домене GET `/mail.php`, после штатной cookie-проверки хостинга, возвращает HTTP 404 и HTML старого WordPress; статус отдельно подтверждён curl. Отправлять заявку в отсутствующий обработчик или заменять проверку новым запросом через WP нельзя считать проверкой новой формы. Реальные POST и письма не отправлены; HTTP-ответ «успех» не подменяет подтверждение доставки.

Для завершения нужны URL развёрнутой Vite-копии с работающим PHP и подтверждение получения одной помеченной тестовой заявки в почтовом ящике. Эти данные запрошены у пользователя. После подтверждения доставки можно установить `indexable: true`, meta `index, follow` только этой странице, пересобрать проект и ожидать 108 URL в sitemap.
