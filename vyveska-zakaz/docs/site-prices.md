# Единые цены на сайте

Дата сверки: 2026-10-19.

Источники и области тарифов хранятся в config/site-prices.json. 67 страниц услуг и корпоративных обзоров получают статические ценовые блоки при сборке; общий прайс формируется из тех же записей через config/prices-catalog.json. В браузере разметка цен не создаётся.

Основной опубликованный прайс: https://xn----7sbbagavscye2ftg.xn--p1ai/ceny/
Расценки отдельных направлений сопоставлены с сохранёнными исходными таблицами docs/pricing-consistency-report.md. Дата актуализации исходных расценок не указана, поэтому сайт называет их опубликованными ориентирами и предлагает подтвердить смету. Прежние запреты на числовые расценки из отчётов пересмотрены по прямому указанию пользователя заполнить цены.

Сторонние источники отмечены kind:market в реестре и подписью «Рыночный ориентир» в интерфейсе. Для примеров из других регионов это отмечено в условии. Числовые примеры — арифметика на указанных ставках с перечислением исключённых работ; они не выданы за полную смету комплексного оформления.
