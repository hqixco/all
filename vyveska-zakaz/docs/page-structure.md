# Предлагаемая структура: решения для каждого URL

Статус: предложение для согласования, без внедрения. Родительский раздел обозначает смысловую иерархию меню, хлебных крошек и перелинковки. Он не меняет путь URL. Например, /fasadnye-vyveski/ остаётся /fasadnye-vyveski/, а не переезжает под /vyveski/.

«Переработать» означает уточнить задачу, улучшить структуру, доказательства и связи; это не требование переписать весь текст. «Оставить» также допускает проверку актуальности. Для статей, кейсов и служебных страниц указан их реальный интент: они не должны превращаться в одинаковые коммерческие лендинги.

Во всех строках текущих страниц URL сохраняется, 301 не назначен. Отдельные кандидаты на объединение разбираются в основном отчёте; окончательное решение ожидает данные запросов и ссылок.
