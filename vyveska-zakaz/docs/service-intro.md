# Вводные блоки услуг

Все 55 вводных блоков используют один компонент по образцу ранее исправленных световых, фасадных и интерьерных вывесок. Данные: config/service-intro.json. Статическую разметку синхронизирует scripts/sync-service-intro.mjs при сборке. Общие стили: public/assets/company-layout.css. У каждой секции сохранён уникальный селектор.

Правки содержания вносить в конфигурацию, общие изменения структуры — в синхронизатор. Проверка исходников и production: npm run intros:check.

Проверено в браузере: 55 страниц на 1440 и 390 px; неон и три исходных образца дополнительно на 1000, 760 и 320 px. Всего 122 проверки, включая совпадение вычисленных стилей, боковые отступы и отсутствие горизонтального переполнения. Скриншоты неона: tmp/neon-intro-1440.png и tmp/neon-intro-390.png.
