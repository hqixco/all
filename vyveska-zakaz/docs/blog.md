# Блог

Данные статей и словарь тематик: `config/blog-articles.json`. Ключи тем стабильные, в нижнем регистре; подписи отображаются на русском. Статья может иметь несколько тем.

`scripts/sync-blog.mjs` перед сборкой обновляет статический HTML статей и двух страниц блога, SEO-метаданные и JSON-LD. Это сборочный скрипт: постоянный контент не создаётся в браузере.

Будущий фильтр может использовать `data-tags` на `.blog-card` и `.article-meta`, а сортировка — `data-published`. Чипы пока информационные, без ложных кнопок и ссылок. Карточки целиком ведут на статьи.

12 дат публикации распределены по месяцам 2023 года по заданию владельца. Дата обновления материалов — 20 октября 2026 года. Автор — организация РПК Ресурс.

Проверки: `npm run blog:check` после сборки; `npm run blog:visual` для локальной проверки ширин 1440, 768, 390 и 320 без JavaScript.
