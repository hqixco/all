# Единый фон первого блока

На 10 страницах блок работ идёт сразу после h1. sync-works.mjs размещает существующий заголовок внутри home-works__wrapper, чтобы h1 и содержимое находились на общем фоне секции. Повторная синхронизация сохраняет этот h1. Текст, тег, id и порядок заголовков сохранены.

Список страниц — config/page-openings.json. Отступ под заголовком задаёт page-opening__title в home-cases.css. Проверка в браузере — tmp/page-openings-check.mjs.

Хлебные крошки также размещены внутри общего блока перед h1. У секции page-opening нет верхнего padding, отступы крошек задаёт page-opening__breadcrumbs. Крошки, заголовок и контент используют непрерывный фон одной секции, отдельной белой полосы нет.
