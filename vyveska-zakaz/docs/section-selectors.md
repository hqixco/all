# Уникальные селекторы секций

Каждому из 901 секционных контейнеров на 118 страницах назначен собственный CSS-класс. Он встречается ровно один раз во всём сайте. Общие классы компонентов сохранены для единых стилей и поведения.

На странице фасадных вывесок используются, например, `.facade-signs-types`, `.facade-signs-selection-factors`, `.facade-signs-lighting`, `.facade-signs-price`, `.facade-signs-production`, `.facade-signs-order-steps`. Полный реестр с адресами страниц и заголовками: `config/section-selectors.json`.

Сборка запускает `scripts/sync-section-selectors.mjs` после синхронизации общих блоков: индивидуальные классы восстанавливаются в статическом HTML, включая FAQ, контакты и кейсы. Затем `scripts/section-selectors-audit.mjs` проверяет исходники и dist: охват контейнеров, принадлежность селекторов страницам и глобальную уникальность. Отдельный запуск проверки: `npm run sections:check`.

При добавлении нового секционного контейнера его нужно включить в реестр с постоянным смысловым именем. Проверка сборки обнаружит незарегистрированный контейнер. При изменении заголовка уже размеченного блока его класс сохраняется.
