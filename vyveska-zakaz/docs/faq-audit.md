# FAQ сайта

На всех 118 маршрутах есть тематические FAQ: по 12 вопросов, на главной — 16. Всего 1420 вопросов. Каждый ответ содержит минимум два содержательных абзаца; минимальный объём — 52 слова.

Содержание хранится в config/page-faq.json. scripts/sync-faq.mjs записывает его в HTML и согласованную FAQPage-разметку до production-сборки. Постоянный контент не создаётся в браузере через JavaScript. Якоря существовавших блоков сохранены.

Услуги раскрывают выбор исполнения, ограничения, исходные файлы, размеры, расчёт, сроки, состав работ и приёмку. Галереи объясняют адаптацию примеров; статьи отвечают по своей теме. Архивные предложения и вакансии не объявлены действующими без подтверждения. FAQ политики пересказывает опубликованный документ, не добавляя новых условий.

Проверка: node scripts/faq-audit.mjs. Проверяются количество вопросов, абзацы и объём ответов, повторы внутри блока, одинаковые полные наборы, совпадение исходного и production HTML с содержанием, единственный FAQPage, соответствие его видимому тексту, уникальность id и отсутствие br.

Браузер: все 118 страниц на ширине 390 px и 10 типовых страниц на 1440 px. Проверены сетка, отсутствие переполнения, количество вопросов и раскрытие ответов. Ошибок JavaScript и нарушений адаптива не обнаружено.
