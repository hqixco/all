# Фотографии факторов

На всех 19 страницах со списками factors-item каждый из 175 пунктов содержит статическое изображение с alt, width и height. Добавлены 123 недостающие фотографии на 15 страницах. Изображения уже были в проекте, новые файлы не создавались.

Общий стиль — public/assets/factor-cards.css: высота 100 px, object-fit: cover, скругление по токену ui-field-radius. Разметка редактируется в HTML страниц. Реестр фотографий — config/factor-photos.json. Проверка исходников и production встроена в сборку: scripts/factor-photos-audit.mjs.
