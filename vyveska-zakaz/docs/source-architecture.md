# Собственные исходники Vite

Реализовано 5 октября 2026 года. Сохранены все 111 существующих страниц и поиск. Добавлены шесть заготовок. Массовой переработки прежних текстов нет. `/` представляет РПК «Ресурс», `/vyveski/` остаётся коммерческой страницей изготовления вывесок. Каждая имеет собственный canonical. Редиректы не добавлены.

## Структура файлов

```text
index.html                         корпоративная главная
pages/<existing-url>/index.html     110 прежних страниц
pages/svetovye-vyveski/index.html
pages/remont-vyvesok/index.html
pages/oformlenie-fasadov/index.html
pages/oformlenie-seti-magazinov/index.html
pages/navigaciya-i-ukazateli/index.html
pages/vyveski-dlya-magazina/index.html
search/index.html
config/site-pages.json             URL, исходник, родитель, связи, статус, очередь, индексация
config/site-navigation.json        дерево основного меню
config/robots.txt
public/assets/navigation.css       стили нового меню и ссылок
public/assets/site.js              поведение; постоянный контент находится в HTML
scripts/sync-navigation.mjs        явное обновление навигации в HTML-исходниках
scripts/archive/wp-migrate.mjs      архив импортера, отключён от build
scripts/archive/normalize-html.mjs  вспомогательный код архива
vite.config.js                     MPA, маршруты dev, стабильные имена, sitemap
dist/<url>/index.html               готовые HTML по прежним адресам
dist/sitemap.xml                    генерируется из реестра
dist/robots.txt                     копируется из config
```

`npm run build` выполняет только Vite: читает собственные HTML, CSS, JS и ассеты, записывает результат в `dist`. WP-каталог и сеть не требуются. Исходники сборка не перезаписывает. Исходный импортёр перенесён в архив и требует явного флага восстановления; запускать его при обычной разработке не нужно.

Постоянная разметка, включая меню, хлебные крошки, ссылки, карточки и модальные окна, присутствует в HTML до выполнения JavaScript. Навигация доступна без JavaScript; с JavaScript на мобильном экране она раскрывается кнопкой.

После изменения дерева в `config` команда `npm run navigation:update` явно обновляет общие блоки в HTML. Эта команда не включена в сборку. Тексты основных секций редактируются непосредственно в HTML. Обе команды завершаются ошибкой при отсутствующих исходниках; сборка также проверяет уникальность URL, наличие родителей и соответствие правил индексации HTML реестру.

## Основное меню

- Вывески → `/vyveski/`: световые, фасадные, интерьерные, неоновые, объёмные буквы, короба, вывески для магазина.
- Услуги → `/services/`: наружная реклама, оформление фасадов и сетей, навигация, ремонт, дизайн, согласование и монтаж.
- Производство → `/services/#production`: печать, фрезеровка, плоттерная резка, брендирование транспорта. Отдельного `/proizvodstvo/` нет.
- Портфолио → `/portfolio/`.
- Цены → `/ceny/`.
- О компании → `/o-kompanii/`: отзывы, сотрудничество, блог, вакансии.
- Контакты → `/kontakty/`.

Все прежние дочерние страницы сохраняются в тематическом дереве реестра. На страницах родителей добавлены ссылки на дочерние направления, на дочерних — обратные ссылки. Для новых направлений предусмотрены дополнительные контекстные связи: световые буквы/короба → световые вывески; фасадные вывески → оформление фасадов; SPAR/портфолио → оформление сети; таблички → навигация.

## Первая очередь

| URL | Родитель | Следующий этап контента |
|---|---|---|
| `/svetovye-vyveski/` | `/vyveski/` | Виды конструкций, реальные фото, цены и условия |
| `/remont-vyvesok/` | `/services/` | Подтверждённые ремонтные работы, диагностика, порядок обращения |
| `/oformlenie-fasadov/` | `/services/` | Комплексное оформление, состав работ, реальные проекты |
| `/oformlenie-seti-magazinov/` | `/services/` | Условия работы с сетями, релевантные кейсы, связь с SPAR |

Вторая очередь: `/navigaciya-i-ukazateli/` и `/vyveski-dlya-magazina/`.

Все шесть новых страниц пока имеют `noindex, follow` и исключены из XML sitemap. В HTML есть H1, краткий вводный блок, контакты, ссылки на портфолио и релевантные услуги. Заготовки не содержат вымышленных цен, сроков или кейсов. После подготовки и согласования полноценного контента нужно согласованно изменить `indexable` в реестре и meta robots в HTML.

Sitemap содержит 107 URL: только страницы с явно установленным `indexable: true` в `config/site-pages.json`. `/page/2/`, `/pechat/page/2/`, `/blog/page/2/` — техническая пагинация, не SEO-посадочные. Они и `/privacy-policy/` имеют `indexable: false`, `noindex, follow` и исключены из sitemap. Все четыре страницы доступны пользователю; robots.txt разрешает обход и не содержит Disallow для них. Проверка SEO сверяет sitemap и meta robots с реестром, включая отсутствие неиндексируемых URL в карте.

## Проверки и границы этапа

Production-сборка и существующие проверки HTML/SEO успешно выполнены для 118 страниц. Повторная сборка сохранила контрольные суммы всех 1165 проверенных исходных файлов. HTTP-проверка локального Vite подтвердила полноценную HTML-разметку по `/vyveski/` и `/svetovye-vyveski/` без выполнения JavaScript. Safari 13 остаётся целевым браузером; имена ассетов стабильные. Визуальная проверка браузером и публикация не выполнялись. Массовое изменение контента и включение новых посадочных в индексацию — следующий этап.
